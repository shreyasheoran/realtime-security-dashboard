# Wireframes

Repository-native wireframes are committed so architecture and UI intent can be reviewed without requiring a Figma account.

- [Desktop alert workspace](desktop-alert-workspace.svg)
- [Mobile alert workspace](mobile-alert-workspace.svg)

## Export and review process

1. Compare the wireframe to the deployed viewport screenshot.
2. Record expected versus observed layout differences.
3. Note rejected deviations and approved refinements.
4. Update the wireframe and implementation in the same change when behavior changes.

## Figma

See the [Figma handoff specification](../figma/handoff.md). A public or authorized Figma URL must be added only after the workspace owner creates it and confirms edit or comment access.
